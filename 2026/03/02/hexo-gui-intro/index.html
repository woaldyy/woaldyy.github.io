|浏览量:

Hexo 的写作流程通常是：新建文件 → 手写 front-matter → 打开终端 → hexo g → hexo s。
对不熟悉命令行的同学来说，这套流程有三个明显的痛点：

  1. front-matter 靠记忆：title、date、tags、categories 少写一个就可能导致归档页异常；
  2. 文章管理靠文件管理器：想找「某个标签下的所有文章」只能靠全文搜索；
  3. 发布流程割裂：写完还要切到终端敲命令，容易忘记 hexo clean 导致样式不生效。

这个工具做了什么

  • 左侧文章列表支持搜索、按状态/标签/分类筛选；
  • 右侧表单化编辑 front-matter，标签和分类可以从已有项里挑；
  • 编辑区提供加粗、标题、列表、代码块等快捷按钮；
  • 内置预览，也能一键在浏览器里看效果；
  • 标签改名会自动同步到所有文章，避免漏改。

工具只是把重复劳动自动化，写作本身还是得靠自己。
