Markdown 写作中的 7 个小技巧

发表于2026-02-18|更新于2026-09-17|技巧
|浏览量:

写博客时间长了，会积累一些让排版更舒服的习惯。

1. 善用二级标题

读者扫读时主要看标题，所以每 300~500 字最好有一个小标题。

2. 表格表达对比

写法 效果 建议
**粗体** 强调关键词 每段不超过 2 处
> 引用 引用他人观点 配合出处
--- 分隔章节 慎用，容易打断阅读

3. 代码块标注语言

4. 图片加替代文字

![示意图](/images/demo.png) 里的文字在图片加载失败时会显示出来，也利于无障碍访问。

5. 列表保持同级

嵌套层级太深会让手机端排版很难看。

6. 用 <!-- more --> 控制摘要

首页只展示摘要，阅读体验更好。

7. 保持 front-matter 整洁

字段越少，迁移主题时越省事。

主题定制：从改配色开始
主题定制不一定要大改，从变量入手最省力。 找到变量文件大多数主题会把颜色、字体抽到 _variables.styl 或 source/css/_variables/ 里。 只改三处 主色（链接、按钮） 正文与背景的对比度 代码块的背景色 12345:root { --brand: #2f6feb; --bg: #ffffff; --code-bg: #f6f7f9;} 改完记得 hexo clean，否则浏览器缓存会让你怀疑人生。
