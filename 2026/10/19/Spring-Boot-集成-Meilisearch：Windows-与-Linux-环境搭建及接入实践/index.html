Spring Boot 集成 Meilisearch：Windows 与 Linux 环境搭建及接入实践

发表于2026-10-19|更新于2026-10-19
|浏览量:

Meilisearch 是一款用 Rust 编写的轻量级全文搜索引擎，以零配置、毫秒级响应和开箱即用的中文支持著称。对于 Spring Boot 项目而言，如果暂时不需要 Elasticsearch 那样庞大的生态和资源开销，Meilisearch 是一个非常值得考虑的替代方案。下面从本地环境搭建开始，分别覆盖 Windows 和 Linux 两种场景，再完成 Spring Boot 的接入与最小可用示例。

一、Windows 本地环境搭建

1.1 手动下载二进制（推荐）

Meilisearch 官方对 Windows 的“官方支持”门槛较高（Windows Server 2022+，Windows 10/11 可能可用但不在正式支持范围内），因此最稳妥的方式是直接从 GitHub Releases 下载预编译的 .exe 文件，而不是依赖安装脚本。

打开 Meilisearch Releases 页面，在 Assets 中找到 meilisearch-windows-amd64.exe，下载后放到一个固定目录，例如 D:\tools\meilisearch\。

几个关键点：

  • addDocuments 是异步操作，返回的 TaskInfo 包含 taskUid，调用 waitForTask 等待索引完成后，文档才可被搜索到。
  • addDocuments 的第二个参数 "id" 指定主键字段名，Meilisearch 据此执行文档的 upsert（不存在则插入，存在则更新）。

四、总结

本文覆盖了 Meilisearch 在 Windows 和 Linux 上的本地搭建方式，以及在 Spring Boot 中通过官方 Java SDK 完成 Client 注册、文档索引和搜索查询的最小闭环。Windows 下建议直接下载 .exe 以避免脚本兼容性问题；Linux 生产环境优先使用 systemd + 二进制 + 反向代理的组合，Docker 方案适合快速验证和开发环境。Spring Boot 侧的核心是声明一个 Client Bean，并在索引完成后用 waitForTask 确保数据可查。在此基础上，可以进一步引入分页、高亮、同义词和 Typo 容错等特性，逐步把搜索能力打磨到生产可用。
